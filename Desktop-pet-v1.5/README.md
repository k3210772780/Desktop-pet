# Windows 双屏桌宠（零依赖版）v1.5

无需安装 PySide6、pynput 或其他软件。项目只使用电脑已有的 Python 标准库、tkinter 和 Windows 系统接口。

## 功能

- 透明、无边框、始终置顶的 PixelPaws 桌宠动画
- 左键拖动并自由放置在当前屏幕任意位置
- 自动读取全部显示器的工作区域，支持负坐标、不同分辨率及双屏穿梭
- 普通、躲猫猫和工作免打扰模式，以及分层行为状态
- 特殊事件气泡、动态右键菜单和极简设置窗口
- 键鼠活动检测不转换或保存字符、具体按键与活动历史，不联网
- 默认支持 PixelPaws 原创猫的 44 帧、22 组动作素材；项目保留其 MIT 许可证
- 表情选择：骄傲、舔毛、哈欠、趴卧、礼物和玩耍
- 躲猫猫：随机藏在任意屏幕边缘，只能通过点击露出的猫咪或等待 30 秒结束
- 工作免打扰：停止自动行为与键鼠反应，状态会保存到下次启动
- 左右行走使用水平镜像，模式、行为和动画分层管理，菜单会禁用冲突功能
- 屏幕数量只在第一次运行时提示一次，普通悬停不再弹出气泡
- 双屏内部边缘允许穿越，虚拟桌面外边缘会阻挡，绝不循环到另一侧
- 每次彻底关闭后重新启动，默认回到第一块屏幕中间下方
- 可选择“位置跟随鼠标移动”；关闭时恢复自主随机活动
- 躲猫猫根据精灵实际透明边界定位，且只使用虚拟桌面外侧边缘

## 启动

双击 `run.bat`。它不会安装任何内容，也不会联网。

PixelPaws 素材文件位于 `assets/pixelpaws/spritesheet.png`。动作表、原图和许可证均已随项目提供；若该 PNG 缺失，程序会自动使用绘制占位角色，不会崩溃。

如果无法启动，双击 `run_debug.bat` 查看提示。退出可右键桌宠并选择“退出桌宠”。

## 隐私

程序仅轮询 Windows 当前按键是否处于按下状态，以区分键盘活动、鼠标移动和点击。按键不会被转换成字符，也不会写入文件；设置文件只保存鼠标跟随、移动速度、免打扰和首次提示状态。
